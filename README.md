
# 🏠 Apartment Rent Prediction System

## 📌 Overview

The Apartment Rent Prediction System is a Machine Learning-based web application developed using Python and Streamlit to estimate monthly apartment rent based on various apartment features. The system allows users to input apartment details and predicts the expected rent using trained Machine Learning models.

---

## 🚀 Features

* Predicts apartment monthly rent instantly
* Interactive Streamlit-based user interface
* Supports multiple Machine Learning models
* Comparison between Linear Regression and Random Forest models
* User-friendly input system for apartment details
* Real-time prediction output

---

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* Scikit-learn
* Pickle
* Machine Learning

---

## 📊 Input Features

The prediction system uses the following apartment details:

* Location
* BHK (Bedrooms)
* Floor Number
* Furnishing Status
* Area in Square Feet
* Age of Building

---

## 🤖 Machine Learning Models Used

* Linear Regression
* Random Forest Regressor
